PROFESSOR ILDEBRANDO LEANDRO - ZOMBIE ATTACK

COMO PUBLICAR NO GITHUB:
1. No repositório jogogames.github.io, crie uma pasta chamada Zombie-Attack
2. Envie TODO o conteúdo desta pasta para dentro dela:
   index.html
   style.css
   game.js
   assets/
3. Faça Commit changes.
4. O endereço esperado será:
   https://jogogames.github.io/Zombie-Attack/

CONTROLES:
A/D ou setas: mover
W / seta para cima / Espaço: pular
F: atirar
K: faca
1,2,3: trocar arma
P: pausar

O jogo também possui controles na tela para celular.
